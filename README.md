# Gnomespotted
<img width="7000" height="4667" alt="logo" src="https://github.com/user-attachments/assets/1fe2d887-d3f5-4369-a5d8-f8b5eca2cd34" />
**Gnomespotted** is a GNOME configuration tool that backups your configuration to help with migration to another GNOME install, lets say you wanted to get a GNOME desktop with all your prefrences and plugins and etc into another system without having to reinstall everything, so you go into the directory of the backup tool and do a chmod +x ./backup.sh, run it and boom. then you copy the zip into the home directory into your other install and get the restore script, go into the direcory again in your terminal and do a chmod +x ./restore.sh and do ./restore.sh.
# Easy done! 
you now have your configuration with plugins and all on your other install!
